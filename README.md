# 我的 Codex Skills

这个仓库用于存放我个人维护的 Codex skills。后续新的 skill 会继续作为独立目录添加到仓库根目录下。

## 当前 Skills

- `technical-cooperation-insight`：分析教授、研究团队、实验室或专家组的 PPT、PDF、论文、报告、会议纪要或文本材料，形成有证据支撑的技术合作资源洞察。

## 目录约定

每个 skill 使用一个独立目录，并至少包含一个 `SKILL.md` 文件。相关参考材料、脚本、agent 配置或模板文件可以放在该 skill 目录下的子目录中。

常见结构示例：

```text
skill-name/
  SKILL.md
  references/
  scripts/
  agents/
```

## 维护原则

- 每个 skill 尽量保持自包含。
- 不提交私密资料、临时输出、账号凭据或本地环境文件。
- 新增 skill 时，在仓库根目录下创建同级目录。

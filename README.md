# My Codex Skills

This repository is a personal collection of Codex skills.

## Skills

- `technical-cooperation-insight`: Analyze technical materials about professors, research teams, labs, or expert groups, then produce evidence-based insight for technical cooperation opportunities.

## Structure

Each skill lives in its own folder and should include a `SKILL.md` file. Supporting files can be placed under that skill's `references/`, `scripts/`, `agents/`, or other local subfolders as needed.

## Notes

- Keep each skill self-contained.
- Avoid committing private source materials, temporary outputs, or credentials.
- Add new skills as sibling folders at the repository root.

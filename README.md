# 我的 Codex Skills

这个仓库用于存放我个人维护的 Codex skills。后续新的 skill 会继续作为独立目录添加到仓库根目录下。

## 当前 Skills

- `technical-cooperation-insight`：基于用户提供的技术材料，整理研究团队信息、材料中的关键技术点和有证据支撑的合作切入方向。
- `paper-insight-extractor`：定义 Paper Insight 风格的论文证据包、抽取字段、中文发表单位、证据边界、方向适配和读者侧周报表达规范。

### `technical-cooperation-insight`

这个 skill 不是万能搜索工具，也不是输入一个关键词后自动检索全网资料的通用研究助手。它更适合在已经有一批素材时使用，由 AI 帮我把材料读透、理清研究团队相关信息，并提炼其中真正可支撑判断的关键技术点。

适合提供的素材包括：

- 研究团队或老师的 PPT、PDF、论文、报告、演讲稿、会议纪要。
- 用户整理过的网页摘录、项目介绍、论文列表、技术路线说明。
- 与目标合作方向有关的背景材料，例如 ADN、网络智能体、数据库、统一云管或其他业务场景说明。

它主要帮助完成：

- 整理研究团队是谁、来自哪里、材料中能确认的研究主题和贡献。
- 提取素材里明确出现的关键技术问题、方法、机制、实验结论和边界条件。
- 根据材料证据，保守判断团队已经展现出的技术能力。
- 结合目标场景，提出少量精准的技术合作切入点，而不是泛泛地做项目规划。

使用时最好同时给出素材和目标场景。只给一个关键词、人名或机构名时，这个 skill 只能做很有限的初步整理；如果需要补充外部资料，应明确说明要联网扩展，并把外部信息和原始素材分开使用。

## 目录约定

每个 skill 使用一个独立目录，并至少包含一个 `SKILL.md` 文件。相关参考材料、脚本、agent 配置或模板文件可以放在该 skill 目录下的子目录中。

常见结构示例：

```text
skill-name/
  SKILL.md
  references/
  scripts/
  agents/
```

## 维护原则

- 每个 skill 尽量保持自包含。
- 不提交私密资料、临时输出、账号凭据或本地环境文件。
- 新增 skill 时，在仓库根目录下创建同级目录。

# 研究团队素材洞察

`research-team-material-insight` 用于在已经有一批素材的前提下，帮助整理教授、研究团队、实验室或专家组的相关信息，并提炼素材中可验证的关键技术点。

它不是万能搜索工具。只输入关键词、人名或机构名时，它不能自动保证搜全、搜准或补齐研究团队资料。这个 skill 的核心价值是阅读用户提供的材料，基于材料证据做归纳、判断和合作方向提炼。

## 适合场景

- 已经有团队介绍、PPT、PDF、论文、报告、会议纪要、网页摘录或演讲稿。
- 需要快速整理研究团队是谁、做过什么、主要技术贡献是什么。
- 需要从材料中提炼关键技术问题、方法、实验结论、能力证据和边界条件。
- 需要结合某个目标场景，判断这个团队可能适合哪些具体合作切入点。

## 需要提供的输入

尽量同时提供以下信息：

- 原始素材：PPTX、PDF、DOCX、论文、报告、会议纪要、网页摘录或粘贴文本。
- 目标场景：例如 ADN、网络智能体、数据库、统一云管、产品线或其他业务方向。
- 阅读对象：例如技术合作团队、研发团队、管理者或外部读者。
- 输出形式：例如聊天文本、内部材料、洞察帖子或 Word 报告。

## 它会帮助整理什么

- 团队身份、单位、研究主题和材料中能确认的主要贡献。
- 素材中明确出现的关键技术点，包括问题、方法、机制、实验结果和限制条件。
- 基于证据的团队能力判断，避免把材料没有支撑的内容写成确定结论。
- 少量具体合作切入点，优先选择与团队已展现能力高度匹配的技术挑战。

## 不适合什么

- 只给一个关键词，让 AI 自动完成全网搜索和完整背景调查。
- 缺少材料时，直接生成确定性的团队画像或合作判断。
- 输出宽泛的项目规划、宣传稿、战略口号或没有证据支撑的合作建议。

## 推荐提问方式

```text
请使用 research-team-material-insight。

下面是某研究团队的 PPT 和论文材料，目标场景是 ADN/网络智能体。
请整理团队信息、素材里的关键技术点、团队能力判断，以及 3 个最适合的技术合作切入点。
请区分材料事实、能力判断、合作建议和参考示例。
```

如果确实需要补充外部资料，可以明确说明：

```text
材料里团队身份信息不足，请在联网补充背景后继续分析。
请把外部信息和我提供的原始素材分开标注。
```
